## noblelift.cz (VZV GROUP s.r.o.)

This folder contains an initial **static prototype** of the Noblelift Czech/English homepage.

### Why a static prototype first
On this computer, `node`, `npm`, and `git` are currently not available in PATH, so scaffolding a Next.js project cannot run yet.
The prototype lets us iterate on:
- layout, typography, spacing
- CZ/EN content
- section order and conversion flow

Once Node.js is installed, we’ll migrate the same layout into Next.js with:
- i18n routing (`/cs`, `/en`)
- SEO metadata + OpenGraph
- reusable components (Header, Hero, Categories, Forms, Footer)
